# ⚽ Football Stats Hub

Football Stats Hub is a full‑stack application designed for football fans, analysts, and developers who want to explore and manage football statistics.  
It combines a **Node.js backend**, a **MongoDB Atlas database**, and a **React + Vite frontend**, all containerized with **Docker Compose** for easy deployment.

---

## 🌟 Key Features
- 📊 **Football statistics** – view team data, league tables, and performance metrics
- 🗄️ **Database integration (MongoDB Atlas)** – secure storage and management of football data
- ⚙️ **Backend API (Node.js + Express)** – handles requests and communicates with the database
- 🎨 **Frontend (React + Vite)** – modern single‑page application interface
- 🐳 **Docker Compose orchestration** – run backend and frontend services together
